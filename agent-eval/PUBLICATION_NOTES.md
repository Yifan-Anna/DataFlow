# 公开发布说明

本地 `.env` 包含运行配置，请仅通过 Git 提交受忽略规则保护的文件，不要将整个本地目录打包或通过网页整目录上传。

## 在新环境配置

1. 将 `.env.example` 复制为 `.env`。
2. 在 `.env` 中填写自己的 `DATAPILOT_API_KEY`，并按所用服务配置地址和模型。
3. 不要将密钥放入 `NEXT_PUBLIC_` 开头的变量；这些变量会出现在浏览器端。

数据库 `backend/data/ecommerce.db` 为本地文件，不提交。后端启动时通过 `backend/data/init_db.py` 自动生成演示订单。指标定义和基准测试数据保留在源码中。

IDE 配置、Python 虚拟环境、依赖、构建缓存、日志和本地数据库已加入忽略规则。`.env.example` 是可公开的配置模板。

## 首次提交前

在要作为仓库根目录的文件夹中初始化 Git，添加文件后运行 `git diff --cached --name-only`，确认暂存列表中没有 `.env`、`.idea`、虚拟环境、数据库和缓存文件。

忽略规则不会从已有提交历史中移除敏感信息。如果密钥此前已提交或分享，应在服务商处撤销并更换，同时清理相关历史。
